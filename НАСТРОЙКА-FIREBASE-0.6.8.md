# Как включить вход и уникальные никнеймы

В APK уже есть код регистрации. Отдельный собственный сервер для входа не нужен: эту работу делает Firebase. Настройки вашей консоли я не менял.

В переданном `google-services.json` правильное имя пакета `kz.youni4st.app`, но нет OAuth-клиентов Google. Поэтому в прежней сборке кнопка Google была серой. В новой сборке кнопка объясняет проблему. Без обновлённого файла настоящий вход Google ещё не заработает.

## 1. Добавьте подпись приложения

1. Откройте Firebase → ваш проект Youni4st → Settings → Project settings → General.
2. Найдите Your apps и Android-приложение `kz.youni4st.app`.
3. В SHA certificate fingerprints нажмите Add fingerprint. Добавьте два значения по отдельности:

SHA-1 этой сборки:
```
BC:20:6A:42:E5:41:10:50:B0:05:A1:7E:50:6F:16:AC:2C:A9:E9:84
```

SHA-256 этой сборки:
```
F4:AD:C6:CE:BC:4C:12:4A:CF:95:B4:61:6C:A3:A2:63:E6:C8:36:85:93:87:B5:8E:6C:E6:FD:C4:64:12:40:22
```

Оба отпечатка также находятся в файле `APK-СЕРТИФИКАТ.txt` рядом с этой инструкцией.

4. Сохраните. В Authentication → Sign-in method убедитесь, что Google включён и указана почта поддержки.
5. Снова скачайте `google-services.json` в Project settings и замените файл `youni4st-android/app/google-services.json` в новых исходниках.
6. Пересоберите APK или передайте обновлённый файл для сборки. Менять код Gradle вручную не требуется. Установите новый APK поверх предыдущего.

При сборке на другом компьютере сертификат может отличаться. Для публикации через Google Play понадобится также добавить отпечатки сертификата подписи Google Play.

Источник: https://firebase.google.com/docs/auth/android/google-signin

## 2. Проверьте вход по телефону

1. Authentication → Settings → SMS region policy: разрешите Kazakhstan / Казахстан.
2. Убедитесь, что SHA-1 и SHA-256 из шага 1 сохранены. Они нужны для проверки приложения и reCAPTCHA.
3. На вашем скриншоте Firebase сообщает ограничение 10 SMS в день. Если лимит исчерпан, используйте e-mail или повторите позже. Включение оплаты — ваше отдельное решение, автоматически она не подключалась.
4. Для проверки без отправки платных SMS можно добавить тестовый номер и код в настройках провайдера Phone. Не публикуйте их вместе с приложением.
5. Если вход не проходит, новая версия покажет код ошибки в квадратных скобках. По нему можно определить проблему, не угадывая.

Источник: https://firebase.google.com/docs/auth/android/phone-auth

## 3. Включите базу никнеймов

1. В Firebase откройте Databases & Storage → Firestore Database → Create database.
2. Создайте базу **Standard edition**, идентификатор **(default)**, режим **Production**. Выберите подходящий регион хранения.
3. Во вкладке Rules откройте файл `firebase/firestore.rules` из этих исходников, скопируйте его содержимое и нажмите Publish.
4. Войдите в приложение. Появится обязательный выбор `@username`. Например, `wombly`.

Если база уже используется другими функциями, сначала объедините её существующие правила с правилами для `handles` и `usernames`, сохранив прежние нужные разрешения. Приложенный файл предназначен для новой базы.

Коллекции создадутся при первом сохранении. Добавлять их вручную не требуется. Никнейм сохраняется в облаке; остальные поля профиля, резюме и избранное пока сохраняются на устройстве.

Регистрация имени выполняется атомарно: база либо сохраняет обе связанные записи, либо не сохраняет ни одной. `Wombly`, `wombly` и `@wombly` — одно имя. При смене ника старое имя освобождается только вместе с успешной регистрацией нового. Нельзя занять чужой ник изменением Android-кода: правила проверяются на стороне Firebase.

Пока база и правила не включены, приложение покажет ошибку регистрации ника, а не ложное сообщение об успешном сохранении. Можно выйти из аккаунта и продолжить пользоваться каталогом без входа.

Источник: https://firebase.google.com/docs/firestore/security/rules-conditions

## Что проверить на телефоне

- Запуск после полного закрытия: заставка должна появляться сразу, затем главный экран; каталог догружается отдельно.
- Введите 10 цифр номера и случайно добавьте одиннадцатую — номер не должен сдвигаться.
- Вход Google, e-mail и SMS после настройки Firebase. Для существующего e-mail выбирайте «Войти», для нового — «Создать аккаунт».
- Один и тот же ник с двух аккаунтов: второй аккаунт получает отказ.
- Микрофон в чате: произнесите вопрос, проверьте полученный текст и нажмите отправку. Доступность диктовки и языков зависит от установленной службы распознавания речи телефона.
