# Youni4st Android · 0.6.0

Нативное приложение на Kotlin + Jetpack Compose. Существующие каталоги и локальные данные сохранены; интерфейс обновлён по предоставленным референсам.

Обновление 0.6.0: [изменения и таймер](docs/CHANGES-0.6.0.md), [проверки](docs/VERIFICATION-0.6.0.md).

Предыдущее обновление: [изменения 0.4.0](docs/CHANGES-0.4.0.md), [источники каталогов](docs/SOURCES-0.4.0.md), [проверки](docs/VERIFICATION-0.4.0.md).

## Базовые возможности

- Единый стиль: тёплый светлый фон, тёмно-синий, бирюзовый и лаймовый акценты, четыре тематические векторные иллюстрации на главной.
- Заставка с логотипом, мозаичной сборкой и системным тактильным откликом (если он разрешён настройками телефона).
- Главная: крупный вход в AI Сократус, горизонтальные кнопки «Гранты», IELTS, «Новости».
- 20 новостей образования с первоисточниками. Подборка проверена 14.10.2026; не обновляется автоматически.
- Вузы: логотипы, раскрывающиеся специальности и контакты, кликабельный счётчик избранного.
- Наставники: фотографии, сведения о площадке/языках/стоимости, избранное, переход по заданной HTTPS-ссылке с показом внешнего адреса.
- Вакансии: логотипы, заметное «Моё резюме», кнопки «Отправить» и «Изменить резюме». «Отправлено» появляется только после подтверждения сервера.
- Резюме: локальное сохранение, фото и экспорт в PDF A4 с переносом длинного текста на дополнительные страницы.
- Новый профиль, экраны входа, поддержки, «О приложении», условий и конфиденциальности. В меню глобуса есть язык, поддержка и сведения о приложении.
- Клиент Firebase Authentication для телефона +7, Google и E-mail; доступ к каталогу без регистрации.

## Что нужно настроить владельцу

**В переданной сборке не настроены Firebase, API приёма откликов, контакты поддержки и ссылки наставников.** Соответствующие кнопки честно показывают недоступность. Выдуманные контакты и фиктивная отправка не используются. AI по-прежнему обращается к существующему backend: его ключ и доступность управляются на сервере.

Пошаговая инструкция с примерами: [docs/EDITING.md](docs/EDITING.md). Контракт отправки: [docs/APPLICATIONS_API.md](docs/APPLICATIONS_API.md). Проверки: [docs/VERIFICATION-0.3.0.md](docs/VERIFICATION-0.3.0.md).

## Открыть в VS Code

Распакуй весь архив. Выбери **File → Open Folder** и открой папку `youni4st-android`, внутри которой одновременно находятся `app`, `gradle` и `gradlew.bat`. APK — готовое приложение; редактируют исходники в этой папке.

Основные экраны лежат в `app/src/main/java/kz/youni4st/app/ui/`, данные — в `app/src/main/assets/`.

## Собрать APK локально

Нужны JDK 17 или 21 и Android SDK (Platform 36, Build Tools 35.0.0). Android Studio запускать не требуется. В корне проекта создай свой `local.properties` со строкой `sdk.dir=C:/Users/ВАШЕ_ИМЯ/AppData/Local/Android/Sdk` (для Windows допустимы прямые слеши).

В терминале VS Code:

```powershell
.\gradlew.bat :app:assembleDebug :app:testDebugUnitTest
```

Результат: `app/build/outputs/apk/debug/app-debug.apk`. Минимум Android 8.0; package ID `kz.youni4st.app`. Для установки поверх старого APK нужна та же подпись. Архив исходников не содержит приватных ключей.

## Собрать на GitHub без нагрузки на компьютер

В репозитории `wombly/youni-android` на момент проверки были только корневые файлы, без `app` и Gradle Wrapper JAR. Загружай **содержимое всей папки проекта**, включая `app/`, `gradle/` и `.github/workflows/android.yml`; ZIP как единственный файл не заменяет исходники.

После загрузки открой **Actions → Android build → Run workflow**. Когда сборка завершится успешно, скачай artifact `youni4st-android-debug`, распакуй его и установи APK. Рабочий процесс уже включён в проект. Он собирает APK, запускает unit-тесты и Lint; запуск на телефоне он не заменяет.

GitHub обычно создаёт собственную debug-подпись: его APK может не устанавливаться поверх локальной сборки. Для последовательных обновлений настрой постоянный ключ через GitHub Secrets; никогда не коммить ключ. Не удаляй старую установленную версию без сохранения нужного резюме: данные пока локальные.

## Проверка на устройстве

APK `Youni4st-0.6.0-debug.apk` предназначен для тестирования. Проверяй избранное, возврат назад, клавиатуру, PDF, крупный шрифт и внешний переход на своём телефоне. Для автоматических сценариев при подключённом устройстве:

```powershell
.\gradlew.bat :app:connectedDebugAndroidTest
```

Реальный SMS/Google-вход и доставка отклика требуют настройки внешних сервисов. Перед публикацией нужны собственная release-подпись и окончательные документы владельца сервиса.
