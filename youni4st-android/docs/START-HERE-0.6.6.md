# С чего начать: регистрация и AI-Сократус

Это инструкция для владельца Youni4st. Здесь не нужно писать код. Сделайте сначала раздел 1, затем раздел 2. Аккаунт Firebase и API-ключ — разные вещи.

## Три понятия простыми словами

- **Firebase** — служба регистрации. Она помогает узнать, кто вошёл в приложение: по телефону, почте или Google.
- **API-ключ AI** — секретный пароль нашего сервера для обращения к поставщику ИИ. Пользователям этот пароль не нужен. В APK его нет.
- **Токены AI** — небольшие части текста. Вопрос пользователя, история разговора, инструкция Сократусу и ответ занимают токены. Длинный разговор обычно требует больше токенов. Это не количество зарегистрированных пользователей и не пароль. Цена зависит от выбранной модели и провайдера.

Пример: пользователь нажал «Как выбрать вуз?» → приложение передало вопрос на наш сервер → сервер обратился к AI → ответ вернулся в приложение.

## 1. Включаем регистрацию: Firebase

1. Откройте https://console.firebase.google.com/ и войдите в свой Google-аккаунт.
2. Нажмите «Создать проект» / Add project. Назовите его Youni4st. Если сервис предлагает дополнительные возможности аналитики, их можно настроить позднее.
3. В проекте выберите добавление Android-приложения (значок Android).
4. В поле Android package name впишите точно: `kz.youni4st.app`. Имя приложения можно указать Youni4st.
5. В настройках Android-приложения добавьте отпечатки сертификата этой тестовой сборки:
   - SHA-1: `BC:20:6A:42:E5:41:10:50:B0:05:A1:7E:50:6F:16:AC:2C:A9:E9:84`
   - SHA-256: `F4:AD:C6:CE:BC:4C:12:4A:CF:95:B4:61:6C:A3:A2:63:E6:C8:36:85:93:87:B5:8E:6C:E6:FD:C4:64:12:40:22`
   Это отпечатки текущего debug-сертификата. Для будущей публикации с другой подписью понадобятся отпечатки именно её сертификата.
6. В меню Firebase откройте Build → Authentication → Get started → Sign-in method.
7. Включите Email/Password. Это регистрация по почте с паролем.
8. Включите Google. Если просят почту поддержки проекта, укажите свою рабочую почту.
9. Включите Phone. Проверьте разрешённые регионы SMS, добавьте Казахстан. Для начала используйте раздел тестовых телефонных номеров Firebase: он позволяет проверить вход без настоящих SMS. Для реальных SMS проверьте требования оплаты и лимиты, которые показывает консоль; стоимость и доступность зависят от текущих условий Google.
10. После включения Google снова откройте Project settings → Your apps → ваше Android-приложение. Скачайте свежий `google-services.json`.
11. Положите этот файл сюда: `Youni4st-0.6.6-source/youni4st-android/app/google-services.json` — рядом с файлом `app/build.gradle.kts`, а не в assets.
12. Напишите мне, что файл добавлен, и попросите пересобрать APK. В этой версии код уже умеет читать его. Не нужно вручную копировать ключи в Kotlin.
13. Установите новую сборку и проверьте сначала регистрацию по почте, затем Google, потом телефон. В Firebase → Authentication → Users должны появиться зарегистрированные пользователи.

Важно: APK, который передан сейчас, не привязан к вашему ещё не созданному Firebase-проекту. Поэтому реальные аккаунты пока не создаются. В нём готовы экраны и код трёх способов входа. Вход сам по себе не переносит локальное резюме и избранное между телефонами: облачная синхронизация — отдельная функция.

## 2. Подключаем AI-Сократуса

Ниже шаги для прямого подключения OpenAI. Сначала нужен отдельный серверный код для OpenAI. В найденной ранее рабочей копии сервер обращался к b.ai: ключи OpenAI и b.ai нельзя просто менять местами. В этом обновлении сервер не развёртывался и его провайдер не менялся.

1. Откройте https://platform.openai.com/ и создайте собственный API-проект. Используйте аккаунт владельца компании, чтобы доступ не зависел от чужого аккаунта.
2. В настройках API-проекта проверьте Billing: способ оплаты, доступный баланс/лимиты и доступные модели. Не предполагается, что подписка на чат автоматически оплачивает сервер приложения.
3. Откройте раздел API keys и создайте ключ для этого проекта. Сохраните его у себя. Не вставляйте его в APK, скриншоты, GitHub или сообщения пользователям.
4. Передайте мне задачу подготовить сервер AI-Сократуса под OpenAI. Секретный ключ для написания кода не нужен. Сервер должен принимать `/api/chat`, использовать ключ из переменной окружения и возвращать поле `reply`, которое уже ждёт приложение.
5. Подготовленный сервер загрузим в отдельный приватный репозиторий GitHub. Android-проект и сервер — две отдельные папки. GitHub хранит код; сам по себе он не запускает постоянно работающий сервер.
6. Откройте https://dashboard.render.com/ → New → Web Service. Подключите репозиторий сервера. Если ваш сервис Render уже существует, сначала проверим его код и логи, чтобы не создавать лишний сервис.
7. Для подготовленного Python/FastAPI сервера с `main.py` укажите:
   - Build Command: `pip install -r requirements.txt`
   - Start Command: `uvicorn main:app --host 0.0.0.0 --port $PORT`
8. В Render откройте нужный сервис → Environment → Add Environment Variable. Имя — `OPENAI_API_KEY`, значение — ваш ключ. Сохраните с запуском нового deploy. `OPENAI_MODEL` можно использовать для выбранной модели только если серверный код читает эту переменную.
9. После успешного deploy откройте адрес сервера с `/ping`. Он должен вернуть короткое сообщение о работе. Затем проверим один запрос чата. В случае ошибки смотрим Logs сервера, не меняем наугад приложение.
10. Адрес работающего сервера указывается в `app/build.gradle.kts`, поле `API_BASE_URL`. Если адрес поменялся — пересоберём APK. Если меняется только секретный ключ при прежнем адресе — новая сборка телефона обычно не нужна.
11. Перед открытым запуском настроим проверку пользователя и ограничения расходов: сколько запросов можно отправить, какая максимальная длина вопроса и ответа. Для проверки пользователя можно использовать Firebase ID token — временный «пропуск» вошедшего пользователя. Это другой вид токена, не единица оплаты AI. Текущий ChatApi ещё не передаёт такой пропуск; этот пункт требует согласованного изменения Android и сервера.
12. Проверим ответы на русском, казахском и английском, отключённый интернет и повтор вопроса. Для точных ответов о вузах Сократусу нужно дать проверенные записи каталога или подключить поиск: один API-ключ не делает сведения автоматически актуальными.

## Что вы делаете первым

**Создайте Firebase-проект и скачайте `google-services.json`.** Это первый самостоятельный шаг. Секретный API-ключ AI пока никуда не отправляйте. После файла Firebase можно собрать версию с работающей регистрацией и отдельно заняться сервером AI.
