# Youni4st 0.6.8

## Запуск

- Включён системный экран запуска Android 8–11, раньше он был отключён `windowDisablePreview=true`.
- Убрана прозрачная системная иконка Android 12+: используется предоставленный знак Y4.
- Новая заставка: тёмный фон, бирюзовое свечение, две тонкие открытые дуги, плавное увеличение знака и подпись Youni4st. Без длинной дополнительной выдержки.
- Главная страница больше не ждёт Firebase и разбора большого каталога вузов. Они загружаются отдельно. Если сразу открыть каталог, до готовности показывается индикатор.
- Прежняя короткая затухающая вибрация сохранена: 280 мс, не блокирует загрузку. Длительность анимации — 850 мс. Настройки в `StartupSettings.kt`.

## Профиль и никнеймы

- На баннере показывается `@username`, без зарегистрированного ника — «Привет!». Дуга смещена левее на 28 dp.
- Убран балл ЕНТ из формы профиля. Телефон необязателен.
- Для зарегистрированного пользователя никнейм обязателен. При первом входе предлагается выбрать его.
- Никнейм регистрируется в Firestore атомарно. Регистр букв не различается; разрешено 3–24 символа, латинская буква в начале, дальше буквы, цифры и `_`.
- Можно изменить никнейм в профиле: прежний освобождается вместе с успешным сохранением нового.
- Правила запрещают присваивать чужие имена и держать несколько имён на одном аккаунте. Они приложены отдельно и должны быть опубликованы в вашей базе.
- Локальные профили разделены по аккаунтам. Прежний локальный профиль переносится при первом входе после обновления. Резюме, интересы и другие персональные поля пока не синхронизируются между телефонами.

## Вход

- Исправлен сдвиг номера при вводе лишней цифры в форме входа и других телефонных полях.
- Вход по e-mail и создание аккаунта обозначены разными кнопками. Ошибка отправки письма подтверждения больше не выдаёт уже созданный аккаунт за неудачную регистрацию.
- Добавлены сообщения о неправильном пароле, занятой почте, истёкшем коде SMS, лимитах, сети и настройках Firebase.
- Кнопка Google объясняет отсутствие OAuth-конфигурации. Для реального входа нужен обновлённый `google-services.json`; исходный файл сохранён без изменений.

## AI-Sokratus

- Микрофон открывает системное распознавание речи на выбранном языке RU/KZ/EN. Распознанный текст добавляется к черновику, автоматической отправки нет.
- Отмена диктовки не удаляет черновик. Если службы распознавания нет, показано понятное сообщение.
- Новая функция не отправляет звук в AI API. Системная служба телефона может использовать интернет для распознавания.

Пользовательские тексты остальных баннеров и существующие `\n` сохранены.
