# Youni4st 0.7.0

- Облачная синхронизация профиля, резюме с фото, избранного, черновиков, истории чата, языка и подтверждений отправки.
- Приватная коллекция `user_data/{uid}` с владельцем, проверяемым по Firebase ID token. Уникальные никнеймы по-прежнему регистрируются атомарно в `handles` и `usernames`.
- Изолированный локальный кэш каждого аккаунта. Данные прежней версии переносятся в кэш соответствующего UID; другой аккаунт получает отдельные данные.
- Устойчивая очередь изменений в SharedPreferences. Подтверждение старой загрузки не стирает более новую локальную правку. Повтор после восстановления сети и при открытии приложения.
- Избранное и черновики сохраняются отдельными полями с отметками удаления; одновременные изменения разных пунктов не стирают друг друга. Изменение резюме не перезаписывает профиль или чат.
- Фотографии передаются как уменьшенные приватные JPEG-копии внутри Firestore. Локальные пути другого телефона не используются. Учитывается поворот EXIF.
- Статус облачного сохранения и ручная синхронизация в профиле. При недоступной базе приложение не сообщает о ложном успешном облачном сохранении.
- Встроен обновлённый пользовательский `google-services.json` с OAuth-клиентом и сертификатом APK.
- Добавлена привязка Google и телефона к одному существующему аккаунту. Отдельные аккаунты не объединяются автоматически.
- Восстановление SMS-обработчиков после браузера/reCAPTCHA, повторный запрос через 60 секунд, ограничение ожидания и защита от устаревших SMS-обработчиков при выборе другого способа входа.
- Ранний нативный экран с логотипом и текстом до Compose. Общий показ заставки — около 2000 мс от первого кадра приложения, короткая вибрация один раз.
- Оптимизированный release APK, подписанный прежним сертификатом для установки поверх 0.6.9. Это ещё не публикация в Google Play.
- Обновлено описание хранения данных в тестовой политике конфиденциальности RU/KZ/EN.

Пользовательские тексты и цвета остальных баннеров, каталог вузов и адрес AI-сервера не менялись.
