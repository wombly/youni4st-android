## Ограничения проверки

На этой машине не удалось получить рабочий Android-эмулятор в ограниченной среде. Поэтому внешний вид, клавиатура, тактильный отклик, PDF-верстка на реальном Android, вход Google/SMS и внешние переходы не подтверждены запуском на устройстве. Нельзя считать компиляцию UI-тестов их прохождением.

PDF создаётся классом Android PdfDocument: A4, переносы строк/страниц, встроенные системные шрифты и ограниченное декодирование фото. `ResumePdfTest` экспортирует длинный пример на русском/казахском, проверяет число страниц и сохраняет PNG для визуального просмотра. Запустить на подключённом устройстве: `gradlew.bat connectedDebugAndroidTest`. В этой сессии демонстрационный PDF не создавался и визуально не проверялся.

Firebase и API приёма откликов не настроены, контакты поддержки/соцсетей и профили наставников не предоставлены. Реальная доставка/авторизация не тестировалась и не имитируется. AI-провайдер текущего backend также не подтверждён рабочим запросом. Каталоги вакансий, грантов и вузов сохранены из прежнего проекта; они не являются проверкой актуальных условий.

## Особенности локальной Windows-сборки

Сохранилась проблема штатного AAPT2: native access violation при завершении ZIP. Локальная обёртка восстанавливает центральный индекс только после проверки всех записанных payload и исходных CRC32, включая случай частично записанного индекса. Повреждённый и обрезанный тестовые архивы отвергнуты, целый архив принят. Длинные команды передаются через штатный daemon-протокол AAPT2. Ресурсы не подменяются. После сборки APK независимо проверен штатными Android-инструментами.

Обёртка подключена только параметром локальной команды; Gradle-проект и GitHub Actions используют стандартный сборщик. Код и описание — в `tools/windows/`. В этой среде Java иногда считает существующий выходной APK недоступным для записи; предыдущий файл был сохранён в рабочую резервную папку, затем создан новый APK.

Проверка Lint читалась из промежуточного XML `lintAnalyzeDebug`; полный генератор отчётов Lint ранее не мог записать текстовый файл в этой среде. Baseline/подавление ошибок не добавлялись. GitHub Actions запускает обычный `lintDebug`.
