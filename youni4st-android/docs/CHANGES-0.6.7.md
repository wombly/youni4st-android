# Youni4st 0.6.7 · 22.10.2026

Основа — исходники 0.6.6, из которых собран APK с Firebase. google-services.json сохранён побайтово.

- Иконка приложения: выбранное владельцем изображение Y4, адаптивные ресурсы пяти плотностей. Логотипы внутри приложения оставлены.
- PDF: фон левой колонки #00B9CD, срединный RGB приложенного образца цвета. Тёмный текст сохранён для читаемости.
- Из формы резюме убран общий «Уровень образования». Степень и записи образования остались; сохранённые ранее данные не удаляются.
- Добавление/редактирование навыка открывается снизу через тот же PersonalSheet, что и интересы.
- Верхняя кнопка «Закрыть»: несохранённые изменения вызывают диалог «Сохранить / Закрыть без сохранения». Сохранение с выходом переводит на «Поиск работы». При выбранном PDF выход выполняется после диалога сохранения файла.
- Заставка сокращена с 1700 до 850 мс. Вместо декодирования всего изображения используется заранее обрезанный логотип 768×142. Каталог загружается параллельно с настройками и Firebase. Сетевых ожиданий при запуске не добавлено.
- Вибрация асинхронная, длительность 280 мс с уменьшением силы; на устройствах без регулировки амплитуды — один короткий импульс. Настройки в StartupSettings.kt.
- Профиль: подпись по умолчанию «Профиль» (имя пользователя продолжает отображаться, если задано), меньший радиус белой дуги и смещение к карандашу. Переносы текста баннера сохранены.
- Гранты, IELTS, Новости: заголовок и избранное стоят в одной строке; отдельная пустая строка под звёздочку убрана.

Установка поверх последнего APK возможна благодаря прежнему сертификату подписи. Данные приложения и Firebase-проект не менялись.
