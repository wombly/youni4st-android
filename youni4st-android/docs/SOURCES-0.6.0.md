- [Паспорта организаций ЕПВО](https://epvo.kz/passport-universities): контакты, адреса, лицензии и программы. В каждой записи JSON указаны source_url и programs_source.
- [КАТО Бюро национальной статистики](https://stat.gov.kz/ru/classifiers/statistical/21/), редакция 18.09.2026: 90 городов.
- [Список ENIC Kazakhstan](https://enic-kazakhstan.edu.kz/page/Organizations_of_higher_and_(or)_postgraduate_education): сопоставление официальных сайтов; устаревшие адреса проверялись отдельно.
- [Программы Nazarbayev University](https://prev.nu.edu.kz/en/academics/allprograms): 71 запись официального списка. Набор на конкретный год необходимо сверять с приёмной комиссией.
- [Военные кафедры — eGov](https://egov.kz/cms/ru/articles/military_service/senior_devision) и страницы самих организаций. У eGov встречается перенаправление после обновления портала.
- Логотипы: публичные загрузки паспортов ЕПВО и официальные сайты. Адрес каждого файла — logo_source. Партнёрские логотипы, телефонная иконка, общий favicon и фотография здания отсеяны при визуальной проверке. SVG двух логотипов преобразованы в PNG без изменения рисунка.

- С рабочим телефоном: 129; с адресом: 151.

Это полный импорт открытого списка ЕПВО, но не утверждение о полноте всех ведомственных вузов страны или всех сведений по каждой организации. Открытые паспорта содержат пропуски; три раздела программ и один паспорт отвечали HTTP 500. Для пустых полей не придуманы адреса, телефоны, наличие общежития или кафедры. Отсутствующие логотипы заменены нейтральной иконкой. Актуальный набор, наличие мест в общежитии, цены и пороги ЕНТ не подтверждены для каждой программы.

Основные направления — навигационная группировка приложения по кодам и названиям программ, а не новая государственная классификация. В разных вузах близкие программы могут называться по-разному. Оригинальные названия сохранены; при отсутствии перевода используется название из источника.

Неполные записи перечислены в CATALOG-COVERAGE.json. Данные открытые, персональные идентификаторы руководителей в приложение не включались.
