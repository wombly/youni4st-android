# Youni4st 0.6.0 · 16.10.2026

## Заставка
- Удалён статичный логотип из стартового окна Android; фон остаётся тёмным.
- Android 12+ закрывает системную заставку без дополнительной exit-анимации.
- Убран попиксельный поиск границ логотипа на UI-потоке. Сразу начинается мозаика с затухающей вибрацией 1,5 секунды.
- Системное окно запуска до первого кадра Android всё ещё существует; полностью убрать время запуска процесса невозможно.

## Поиск вузов
- 90 городов по КАТО от 18.09.2026, включая города без вузов.
- После выбора города появляется «Город и область» с выбранным городом первым и другими городами региона.
- Алматы, Астана и Шымкент не объявляются частью области: для них показываются соседние Алматинская, Акмолинская и Туркестанская области соответственно.
- 22 основных направления, затем поиск конкретной программы с уровнем образования. Зависимый выбор сбрасывается при смене города/направления.
- Медицинская резидентура отделена подписью от бакалавриата и не предлагается как прямой маршрут после школы.
- Поиск вуза по названию, программы — по названию/коду. Длинные списки используют LazyColumn.
- Избранное сохраняется: две старые карточки-факультета объединены с карточкой соответствующего вуза.

## Сведения и логотипы
- Все 159 записей открытого списка ЕПВО на дату проверки. Среди них есть филиалы, академии и организации послевузовского медицинского образования — это НЕ 159 отдельных классических университетов.
- 85 проверенных логотипов/фирменных значков хранятся в assets и работают офлайн; для остальных — нейтральная иконка.
- Контакты, адреса и программы импортированы из публичных паспортов; список NU дополнен официальным сайтом.
- Общежитие и военная кафедра отмечаются только при наличии источника. Отсутствие подтверждения означает «Уточняется», а не «Нет».
- Старые общие пороги ЕНТ и цены не выдаются за актуальные: требования зависят от программы. Неизвестный порог не скрывает вуз по фильтру баллов.
- Пользовательские изменения шрифтов/цветов главного экрана из версии 0.5.0 сохранены.
