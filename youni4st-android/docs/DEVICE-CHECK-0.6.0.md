# Проверка на телефоне

1. Установить APK поверх предыдущей локальной версии (подпись сохранена), не удаляя приложение с резюме и избранным.
2. Полностью закрыть и запустить приложение: после короткого системного тёмного окна должна сразу начинаться мозаика, без отдельного статичного логотипа. Проверить затухание вибрации на устройстве с поддержкой управления амплитудой.
3. В поиске вузов выбрать Алматы. Должен появиться второй список: Алматы первым, затем города Алматинской области. Выбрать Каскелен, проверить SDU. Сменить первый город на Астану: старый дочерний город должен сброситься.
4. Выбрать «Медицина», затем найти «Нейрохирургия». Подпись должна указывать резидентуру. Переключиться на «Инженерия»: медицинский дочерний фильтр должен сброситься.
5. Открыть крупный вуз и его программы, проверить поиск и прокрутку. Открыть контакты и сведения об общежитии/кафедре.
6. Отключить интернет и открыть несколько карточек: встроенные логотипы остаются доступными. Там, где официального изображения нет, показывается нейтральная иконка.
7. Проверить избранное, особенно старые отдельные карточки факультетов ЕНУ и КАУ: они объединены с ЕНУ и МОК соответственно.
8. Проверить увеличенный системный шрифт, маленький экран, клавиатуру и поворот телефона. После блокировки более чем на пять минут заставка повторяется, введённые данные сохраняются.

Этот список подготовлен для ручной проверки. Подключённого Android-устройства в среде сборки не было.
