Дата: 13 октября 2026 года. Это первая тестовая Android-сборка.

- `:app:assembleDebug`: APK успешно собран, Kotlin и Java скомпилированы.
- `:app:testDebugUnitTest`: 7 тестов, 0 ошибок, 0 падений. Проверены границы балла ЕНТ, совместная работа фильтров, сериализация резюме, локализованные данные каталогов, POST-контракт AI и обработка ошибочных ответов.
- `:app:compileDebugAndroidTestKotlin`: три инструментальных сценария скомпилированы; на устройстве не запускались.
- Android Lint: в сохранённых результатах анализа 0 ошибок и 17 предупреждений (новые версии зависимостей и рекомендации использовать KTX). Обнаруженное замечание к экранированию пути SDK в локальном `local.properties` исправлено; этот файл не входит в архив исходников.
- `apksigner verify --verbose`: подпись APK v2 валидна.
- Официальный `aapt2 dump badging` прочитал готовый APK: `kz.youni4st.app`, версия `0.1.0`, minSdk 26, targetSdk 36, стартовая Activity присутствует.
- Все 138 записей внутри APK прочитаны с проверкой исходных CRC32 и размеров; расхождений нет.

## Особенность локальной сборки

Нативный AAPT2 в данной Windows-среде падал с кодом `0xc0000005` на завершении ZIP даже на минимальном тестовом приложении. Для сборки применена временная обёртка: она восстанавливает только индекс архива после проверки всех записанных данных и не меняет содержимое ресурсов. Повреждённый CRC и обрезанный файл на отдельных тестах были отвергнуты. Исходник и описание находятся в `tools/windows`.

Обёртка подключалась параметром командной строки только при этой сборке. Конфигурация проекта и GitHub Actions используют стандартный Android Gradle Plugin. APK после сборки проверен штатными Android-инструментами.

Генератор текстового отчёта Lint также не смог записать файл в данной среде. Результат анализа прочитан из промежуточного XML; ошибки не отключались и baseline не создавался. Это ограничение локального формирования отчёта.

## Что ещё не подтверждено

- Приложение не запускалось на физическом телефоне. Эмулятор в этой среде не стартовал: аппаратное ускорение недоступно, для программного режима не хватило доступной памяти. Подключение через ADB также не удалось.
- Визуальная проверка экранов и инструментальные UI-тесты на устройстве ещё не выполнены. Скриншоты в `docs/references` — исходные ориентиры пользователя, а не снимки этой сборки.
- Успешный ответ действующего AI-сервера не подтверждён: проверка `/ping` завершалась по тайм-ауту. Тесты API выполнены с локальным тестовым HTTP-сервером.
- Авторизация, синхронизация, отправка откликов и реальная запись к наставнику пока не подключены. Черновики сохраняются локально, что явно обозначено в интерфейсе.
- Каталоги перенесены из Mini App; актуальность вакансий, цен и сроков отдельно не проверялась. Иллюстрации главной временные.

## Первый проход на телефоне

1. Открыть главную и каждый раздел нижней навигации.
2. Ввести балл ЕНТ, выбрать город и направление, открыть вуз и добавить его в избранное.
3. Открыть вакансию и наставника, сохранить и удалить черновик.
4. Заполнить резюме, выбрать фото, сохранить, перезапустить приложение и проверить данные.
5. Переключить язык; проверить длинные заголовки и увеличенный системный шрифт.
6. Отправить вопрос AI и проверить ответ либо понятное сообщение об ошибке.
