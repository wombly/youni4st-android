## Практические ограничения проверки

К компьютеру не подключено Android-устройство. Проверки UI на устройстве, работа клавиатуры, колёс даты, вибрация и фактический Android-экспорт PDF в этой сессии не выполнялись. Команда для запуска сценариев на подключённом устройстве: `gradlew.bat connectedDebugAndroidTest`.

Перед распространением проверить на телефоне: ввод и прокрутку резюме с открытой клавиатурой; выбор 29 февраля и смену года; добавление, изменение, удаление и повторное открытие записей; отмену и успешное завершение экспорта PDF. В системном диалоге сохранения PDF должна выбираться реальная папка, после чего файл можно открыть обычным PDF-просмотрщиком.

Использованы прежние зависимости проекта и настройки Gradle для небольшого объёма памяти. Для локальной Windows-сборки применена уже существующая обёртка AAPT2; обычная сборка проекта использует штатный инструмент AGP. Действительный результат APK дополнительно проверен штатными `aapt2` и `apksigner`.

Финальная команда assembleDebug + testDebugUnitTest + compileDebugAndroidTestKotlin + lintAnalyzeDebug завершилась BUILD SUCCESSFUL. В отчёте lint-definite: 0 ошибок, 15 предупреждений (KTX, совместимые копии логотипа и рекомендации инструментов).
